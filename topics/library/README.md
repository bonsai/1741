# 公共図書館

## 目的
公共図書館への公的投資、施設・サービス、利用実績を自治体・都道府県単位で比較する。

## 初期調査：図書館費ランキング
- 図書館費の総額ランキング
- 人口一人あたり図書館費ランキング
- 予算と決算を別系列で集計
- 資料費も可能な範囲で独立指標として集計
- 都道府県は47件すべて、市区町村は比較可能なデータから上位100件を掲載
- 和歌山市の予算規模・内訳・年度推移を重点調査

## 比較上のルール
- 図書館費、資料費、社会教育費中の図書館支出を別指標として保持する。
- 県立・市町村立の対象範囲を確認し、二重計上を避ける。
- 予算と決算を混在させない。
- 欠損値をゼロ円として扱わない。
- 順位に対象年度、対象自治体数、取得率、費目定義、出典を付ける。
- 支出額だけで政策の充実度を断定せず、施設・蔵書・貸出・来館・アクセス等と併せて読む。

## 優先データソース
- e-Stat／文部科学省「地方教育費調査」
- 日本図書館協会「日本の図書館 統計と名簿」（利用条件を確認し、無償公開データを優先）
- 自治体の予算書・決算書・オープンデータ
- e-Stat人口統計
