# 地域文化エコシステム

## 目的
民謡・民舞・祭り・伝統行事などの文化資源と、保存会・演者・住民・学校・大学・自治体・企業・NPO等の担い手や支援主体を調査する。

## 調査領域
- 文化資源の所在・歴史・伝承状況
- 保存会・継承者・演者・教育機関などの担い手
- 保存・継承・教育・公演・記録・発信の活動
- 行政支援と民間・地域主体の活動の区別
- 観光活用、文化参加、地域間連携

## データ方針
文化資源・主体・関係・活動は独立したエンティティとして扱う。自治体に従属させず、多対多の関係として記録する。共通データの正本は `records/`、`data/`、`assessments/` とし、このトピックでは調査・分析を蓄積する。

## 民謡・民踊の調査単位

民謡（歌）と民踊（踊り）は関連していても別々の文化資源として記録する。

- 民謡: 曲、歌詞、旋律、唄い手、演奏者、楽器、録音、歌唱機会、伝承地域。
- 民踊: 踊り、振付、所作、隊形、踊り手、指導者、稽古、伝承団体、実演記録。
- 民謡と民踊の関係: 使用音源、伴奏、歌唱との同時実演、イベントでの採用等、根拠のある関係として記録する。

「民舞」は原資料の用語を尊重し、民踊と同義と決めつけない。イベントで踊られたことだけで、伝承民踊の存在や継承状況を推定しない。民謡の歌唱継承と民踊の踊り・振付継承は別々に調査する。
