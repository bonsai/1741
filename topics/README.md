# Topics

調査・分析テーマは `topics/{topic_id}/` ごとに独立したディレクトリで管理する。

各トピックのディレクトリを調査単位の作業場所とし、定義・データソース・収集コード・加工データ・分析・成果物をまとめる。自治体マスターや共通スキーマなど、複数トピックで共有する基盤データは各トピックに複製せず、既存の共通ディレクトリを参照する。

## 初期トピック

- `library/`: 公共図書館。図書館費・資料費・施設・利用実績の比較を含む。
- `cultural-ecosystem/`: 地域文化エコシステム。文化資源・担い手・保存継承・活動・支援を調査する。
- `foreign-residents/`: 外国籍住民。人口・構成・地域差などを調査する。
- `birth-dynamics/`: 出生動態。出生数・普通出生率・合計特殊出生率を区別して調査する。

## 標準構成

トピックごとに必要なものから作成する。空ディレクトリはGitで管理できないため、各ディレクトリにこのREADMEを置く。

- `README.md`: 目的、調査範囲、指標、進捗
- `sources/`: トピック固有のデータソース台帳
- `scripts/`: 収集・正規化・集計スクリプト
- `data/raw/`: 原データ（再配布条件を確認）
- `data/processed/`: 正規化・集計データ
- `notebooks/`: 探索・検証用ノートブック
- `analysis/`: 分析メモ・ランキング・レポート

共通データの正本はリポジトリ直下の `data/`、共通指標は `indicators/`、共通観測値は `observations/` とする。トピック内には必要に応じて生成物や分析用ビューを置き、共通データを二重管理しない。
