## 概要

熊本に結びつく民謡。熊本弁による歌詞や軽快な旋律で知られ、民踊・舞台・地域イベント・観光発信など複数の形で親しまれている。

成立時期、作者、モデルとされる人物、歌詞の異本、録音・普及の歴史については、伝承・研究・一次資料を区別して調査する。人物モデル等の説を確定した史実として扱わない。

## このレコードの考え方

おてもやん自体を文化資源として独立登録する。熊本県・熊本市のどちらかに所有・帰属させない。自治体、保存団体、演者、教育機関、イベント運営者、観光関係者などとの関係を個別に記録する。
