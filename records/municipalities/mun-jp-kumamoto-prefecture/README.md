## 1919での扱い

熊本市とは別の地方公共団体として登録する。県域の文化政策、広域的な文化振興、県内自治体・文化団体との連携を調査する。

## おてもやんとの関係

現時点では関係を確定しない。県の文化政策・民俗芸能支援・広域事業・補助制度等の一次資料を調査し、確認できた役割を文化資源側の関係記録に追加する。
